# Advanced Algorithms I - CS206028

Weekly contest solutions and repository for the Advanced Algorithms I course at the Free University of Tbilisi.

## Course Information

- **Course**: Advanced Algorithms I (CS206028)
- **Institution**: Free University of Tbilisi
- **Academic Year**: 2025-2026

## Course Syllabus

### 1. Fundamentals & Elementary Algorithms

- Designing algorithms for elementary problems
- Efficient software implementation of algorithmic solutions

### 2. Basic Data Structures

- Stacks, Queues, and Deques
- Linked Lists and their modifications

### 3. C++ Standard Template Library (STL)

- Efficient usage of STL containers: `vector`, `stack`, `deque`, `queue`, `priority_queue`
- Associative containers and bit manipulation: `set`, `map`, `bitset`

### 4. Graph Theory Foundations

- Graph types, properties, and definitions
- Efficient graph representation and storage techniques

### 5. Graph Traversals & Applications

- Breadth-First Search (BFS) and Depth-First Search (DFS)
- Tree traversals and cycle detection
- Topological Sorting
- Connected components and Strongly Connected Components (SCC)
- Finding Bridges and Articulation Points (Cut Vertices)

### 6. Shortest Paths in Graphs

- Bellman-Ford algorithm
- Floyd-Warshall algorithm
- Dijkstra's algorithm
- Johnson's algorithm

### 7. Minimum Spanning Trees (MST)

- Prim's algorithm
- Kruskal's algorithm

### 8. Exponential Algorithms

- Bitmasks and their applications in optimization/dynamic programming

### 9. Binary Indexed Trees

- Fenwick Trees for logarithmic range queries and point updates

### 10. Interval Trees

- Segment Trees and their application for logarithmic range operations

### 11. Dynamic Programming (DP)

- Core principles of Dynamic Programming
- Dissecting classical and advanced DP optimization problems

### 12 & 13. Computational Geometry

- Vectors, lines, and fundamental geometric operations
- Line segment intersections
- Convex Hull construction (Graham Scan / Jarvis March)

### 14. String Matching Algorithms

- Efficient pattern matching and string searching algorithms

### 15 & 16. Suffix Structures

- Suffix Trees — Ukkonen's construction algorithm and applications
- Suffix Automata — Construction, properties, and applications

## Repository Structure

The repository is organized by weekly contests. Each contest directory contains:

- `README.md` - Links to the specific Codeforces problems
- Problem solutions (`problem-01`, `problem-02`, etc., implemented in C++)

## Building and Running

Solutions are written in C++. To compile and run via the terminal:

```sh
g++ -std=c++17 -O2 solution.cpp -o solution
./solution
```
